# LNBQSHA — Global Social Game Universe

## Product Overview

LNBQSHA is a **social game universe platform** built on top of Nakama. It combines:
- **Play** — Multiplayer games (Obstacle Rush, racing, survival, strategy)
- **Social** — Friends, parties, chat, presence, activity feed
- **Discovery** — Friends-of-friends, activity discovery
- **Progression** — Level, XP, achievements, daily rewards
- **Economy** — Soft currency, premium currency, wallet, transactions
- **Monetization** — Cosmetics store, premium tournaments, revenue sharing
